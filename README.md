A top-down stealth heist game: slip through the Halcyon Museum at night, dodge guard patrols and sweeping security cameras, lift the Aurora Diamond, and make the getaway van before the alarm hits the roof.

Play it: open `game/index.html` in a desktop browser (or run `node serve.ts` and visit http://localhost:8080). Move with WASD or arrow keys, hold Shift to sneak, E to grab loot and interact, Q to use a tool.
